Privacy disclosure

Data accessed and purpose

The application reads aggregated Google Analytics reports for websites the owner is authorized to access. Data includes sessions, users, engagement, pages, events, traffic channels and campaigns. It is used only to provide the requested website and marketing reports. The only Google permission requested is analytics.readonly; the app does not request Gmail, Drive, Apps Script or write permissions.

Credentials, storage and providers

With the owner's explicit approval, the dedicated OAuth client secret and refresh token are stored in private GitHub Actions Secrets. Each approved run exchanges the refresh token for a short-lived access token in process memory over HTTPS. Tokens are not included in reports, Issues, artifacts or application logs. Google handles authorization and API requests; GitHub hosts the workflow, encrypted Secrets and private report artifacts.

Reports are accessible to the owner and people with relevant private repository permissions. People who can change trusted workflows can potentially access runtime credentials. Generated artifacts are configured to expire after seven days. Sanitized logs follow the repository's retention setting. Downloaded copies are controlled by the person who downloads them. Credentials remain until deleted, revoked or invalidated; the application creates no access-token cache.

Owner-directed analysis

If the owner chooses to submit a report to ChatGPT Work, the report is processed by OpenAI under that account's service settings. The tool does not provide OAuth credentials to ChatGPT or other models. It does not sell Google data, use it for ad targeting, or train general-purpose models with it. Google data use must comply with the Google API Services User Data Policy, including applicable Limited Use requirements.

Control and deletion

The owner can stop runs, delete the corresponding GitHub Secrets and artifacts, and revoke this independent application's access through Google account connections. Revocation or permission loss stops collection with sanitized diagnostics. Original production-report and clasp authorizations remain separate. Downloaded report copies and retained logs must be deleted separately.

This public information site

This site uses no application cookies, analytics scripts, forms or external fonts. The static hosting provider may log visitor IP addresses for security under its own privacy policy. This site never receives Google authorization codes or tokens.

Contact and changes

Contact the owner using the support address shown on Google's consent screen or your established private contact with the owner. Changes to data use will be disclosed before use, with renewed consent when required.
