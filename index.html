Carloha Insights Hub GA4 Read Only

A private, owner-operated tool for read-only website and marketing reporting.

The owner authorizes Google Analytics access in Google's own consent screen. Approved runs use private GitHub Actions to read website traffic, engagement, pages, events, channels and campaigns, and generate Excel and JSON reports. Other marketing sources remain separately identified.

This information site has no sign-in form, API, tracking script or credential storage. It does not display analytics reports. Collection and report access remain private.

The Google permission requested is analytics.readonly. It permits reading Analytics data the account can access; application code limits queries to configured Properties. It does not permit changing Analytics settings, ads or production reports.

Read the privacy disclosure and access and use information before granting access. This application is not open for public registration.
